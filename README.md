# 📜 The 1689 Confession

**The Second London Baptist Confession of Faith (1677/1689), beautifully typeset for the web — all 32 chapters with every scripture proof readable inline in three public-domain translations.**

**Live:** [1689.intentmesh.dev](https://1689.intentmesh.dev) · also served at [intentmesh.dev/1689](https://intentmesh.dev/1689/)

---

## ⚡ Quick Facts

| | |
|---|---|

| **Translations** | BSB (default) · KJV · WEB · side-by-side Parallel view |

## ✝️ Text Fidelity

A word-level collation against the 1677 original-spelling edition exposed **three clauses dropped by the common internet e-text family** (Wikisource, GRBC, TGC, ReformedReader). All three are restored here:

| Ref | Restored clause |
|-----|----------------|
| **10.2** | "co-working with his special grace, the creature" |
| **11.1** | "they receiving and resting on him and his righteousness" |
| **25.3** | "It is lawful for all sorts of people to marry, who are able with judgment to give their consent" |

Six corrupted proof references in the common e-text were also corrected against historical editions (e.g. Genesis 1:20 → **Genesis 50:20**, Psalms 1:21 → **Psalm 50:21** in ch. 5 ¶4).

## 🗂️ Repository Layout

| Path | Purpose |
|------|---------|
| `confession.json` | Canonical text — chapters → paragraphs → text + proofs |
| `build.py` | Generates `public/index.html` plus robots.txt, sitemap.xml, llms.txt, 1689.md |
| `build_verses.py` | Resolves all 770 proof refs to verse text in BSB/KJV/WEB → `public/verses.json` |
| `worker.js` | Serves assets; internally rewrites `intentmesh.dev/1689/*` (no cross-origin redirect) |
| `wrangler.jsonc` | Cloudflare config — custom domain + zone route |
| `public/` | Generated site (committed so the repo is deployable as-is) |

## 🚀 Build & Deploy

```bash
python3 build.py                 # regenerate public/ from confession.json
npx wrangler deploy              # deploy worker + assets to Cloudflare
```

`build_verses.py` additionally requires local copies of the BSB flat file and KJV/WEB verse sets (paths at the top of the script); its output `public/verses.json` is committed, so it only needs re-running when proofs change.
